# V0.1 Limitations — Engineering Platform

> 诚实记录 V0.1 的已知限制（2026-08-14，EP-WORK-010A 收口时点）。
> 不得因为"想发布"而隐瞒；这些限制是 V0.1 的边界，不是缺陷掩盖。

## 运行时 / 环境限制

1. **JDK25 本地 Build Gate 尚未执行**：正式基线 Java 25，本机 JDK 21.0.11。
   `JDK25_BUILD_GATE = PENDING`；`TESTS_EXECUTED = NO` / `TESTS_PASSED = NOT_VERIFIED`。
   静态编译（javac --release 21）PASS 不构成运行通过证明。
2. **Maven Wrapper 未生成**：`MAVEN_WRAPPER_PENDING`。离线环境无法从未知来源安全下载
   wrapper jar；不伪造 wrapper。CI 使用 GitHub Actions 显式 setup-java 25。
3. **网络受限**：Maven 依赖解析受代理不可达影响；JUnit 使用本地 m2 可用版 6.0.1
   （同为 JUnit 6 系列，未改技术栈）。

## 功能限制

4. **无真实 Agent Adapter**：只有 Agent-neutral `AgentAdapter` 接口 + FakeAgentAdapter。
   OpenClawAdapter / CodexAdapter / 其他 Adapter 未实现（且不是 Platform Core 依赖）。
5. **Browser capability 未实现**：`BROWSER_READ/WRITE` 已定义（Capability V1），
   但 ToolPolicyEvaluator 对 Browser 一律 DENY（"not implemented in V1"）。
6. **Shell Guard 不是 OS sandbox**：是 V1 Policy Guard（白名单 + 高危黑名单 + 结构化命令），
   不提供完整进程隔离 / seccomp / cgroup。Policy Guard ≠ Runtime Sandbox。
7. **Approval 无 UI**：只有 Contract + Policy 状态（PENDING/APPROVED/REJECTED/EXPIRED）；
   没有审批界面 / 通知 / 自动过期调度。
8. **CUSTOM criterion 等价 PENDING_MANUAL**：V1 不实现自定义规则引擎。
9. **WorkItem 状态迁移 Guard 未实现**：状态枚举 + 验收决策引擎已实现；
   迁移 Guard（V0.7 §23）归后续 Workflow 层。

## Contract-only / SKIPPED 操作

10. **Operation 类型部分 Contract-only**：GenerationPlan OperationType 含
    REGISTER_MODULE / REGISTER_PROVIDER / ADD_MAVEN_MODULE / ADD_DEPENDENCY /
    ADD_FRONTEND_PACKAGE / ADD_ROUTE / ADD_PERMISSION / ADD_MIGRATION / ADD_TEST / ADD_GUIDE，
    Executor V1 只执行 CREATE_DIRECTORY / CREATE_FILE / UPDATE_MANAGED_FILE / DELETE，
    其余在 Contract 中保留、执行时记录为 SKIPPED（不假装 SUCCESS）。
11. **Planner V1 不自动产生 DELETE**：DELETE 高风险，需调用方显式请求。
12. **Evidence 引用不带内容寻址校验**：只记录引用 + metadata；内容校验归 Artifact Store（未实现）。
13. **Manifest Runtime Validator 是最小结构校验**：EP-WORK-002 正式 Java 实现为
    `ManifestRuntimeValidator`（schemaVersion / required fields / 已知 enum）；
    完整 JSON Schema engine binding 标记 `JDK25/DEPENDENCY GATE`。
    事实 Schema 仍是 Python validators（build-time）。

## 其他

14. **ScopeVerifier 基于字符串路径匹配**：支持前缀 / `**` / 精确三种模式，无完整 glob 库。
15. **CREATE_DIRECTORY rollback 保守**：目录非空不删除（避免误删用户后续文件）。
16. **无真实 Template Engine**：Generator 只产生 Plan + 骨架执行，模板库未选型
    （V0.7 G5 允许施工阶段 ADR）。
17. **无数据库 / 无权限管理后台 / 无生产部署系统**：V0.1 是工程基线，不是产品系统。
